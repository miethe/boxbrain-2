# BoxBrain v2 — Wiki Spec

## Domain

BoxBrain v2 is a governed enterprise slide and content catalog for decomposing business artifacts into atomic ContentUnits, organizing them by family, variant, and version, and composing reusable Storyboards with provenance, review, and search controls.

## Topics

- Content decomposition: atomic ContentUnit model, family/variant/version taxonomy, provenance tracking
- Storyboard composition: reusable content assembly, review workflows, search and discovery
- Architecture: Next.js frontend, FastAPI backend services, shared API contracts, pnpm monorepo layout

## Conventions

- Hand-curate: naming, tagging, and routing conventions for this project's artifacts
